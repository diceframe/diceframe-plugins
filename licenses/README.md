# License texts

Plain-text licenses from [SPDX license-list-data](https://github.com/spdx/license-list-data/tree/main/text), used to write a LICENSE file for hosted content packs that do not include one (see `scripts/content-hosting.cjs`).

The file name is the SPDX identifier. Add a file here before offering a new license in `.github/ISSUE_TEMPLATE/add-content-pack.yml`.
